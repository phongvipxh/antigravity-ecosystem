## ⚡ 2. The 18 Specialized Skills (`skills/`)

Skills extend the agent with domain-specific algorithms, design tokens, and automation tools:

### 📐 System Architecture & Diagrams
- **`archify`**: Compiles standalone, interactive HTML architecture, sequence, and workflow diagrams with 9 deterministic artifact checks, dark/light themes, and real SVG brand badges.
- **`architecture-planner`**: Architectural requirement decomposition, risk management, and multi-file initiative checkpoints.

### 🎨 Elite Visual Design & Frontend Systems
- **`high-end-visual-design`**: Agency-tier ($150k+) visual design system. Enforces double-bezel hardware chassis (`Doppelrand`), button-in-button CTAs, OLED black palettes, and fluid cubic-bezier kinetics.
- **`minimalist-ui`**: Clean Swiss editorial layouts. Warm monochrome palettes, high-contrast typography, and flat bento grids.
- **`industrial-brutalist-ui`**: Raw mechanical and military terminal aesthetics. Technical blueprint grids and declassified wireframe visuals.
- **`design-taste-frontend`**: Anti-slop frontend engineering. Real design tokens, zero templated looks.
- **`hallmark`**: High-aesthetic greenfield creation, visual audit, and design extraction from URLs/screenshots.
- **`impeccable`**: Systematic UX design review, cognitive load optimization, micro-interactions, and accessibility.
- **`redesign-existing-projects`**: Upgrades generic AI websites into premium agency-grade experiences without breaking logic.

### 🔍 Deep Research & Scraping
- **`deep-codebase-researcher`**: Traces call graphs, data lifecycles, and architectural invariants across large repositories.
- **`browser-search`**: Multi-engine real-time web research (SearXNG + Camofox + CloakBrowser).

### 🧪 Testing, Debugging & Reliability
- **dynamic-harness-runner**: Authors and executes task-specific ephemeral test harnesses on-the-fly (Claude Code dynamic workflows & Codex Core execution plane pattern) for multi-candidate tournaments, bounded sweeps, and trajectory sampling.
- **`systematic-debugging`**: 4-stage root-cause isolation protocol adapted from Claude Code and Roo-Code.
- **`test-driven-development`**: Standardized TDD workflow for regression prevention.
- **`playwright-testing-and-automation`**: Headless browser automation, E2E UI testing, and responsive layout verification.
- **`zero-hallucination-checker`**: Pre-flight verification checklist eliminating API, package, and CLI hallucinations.
- **`full-output-enforcement`**: Overrides LLM truncation; strictly bans code abbreviations or placeholders.
- **`project-state-manager`**: Adaptive Project State and Memory Bank manager for continuous sessions.

## 🚀 4. Quickstart: 1-Click Deployment

### Windows (PowerShell)
```powershell
# Clone the repository
git clone https://github.com/phongvipxh/antigravity-ecosystem.git
cd antigravity-ecosystem

# Run the installer
.\install.ps1
```

### macOS / Linux (Bash)
```bash
# Clone the repository
git clone https://github.com/phongvipxh/antigravity-ecosystem.git
cd antigravity-ecosystem

# Run the installer
chmod +x install.sh
./install.sh
```
